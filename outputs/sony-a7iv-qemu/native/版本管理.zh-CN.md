# 版本管理

当前项目版本固定为 **v0.1**，仓库根目录 `VERSION` 内容为 `0.1`。Git 的 `v0.1` 标签标记当前可复核的基线。后续工作继续通过新提交记录，未经明确要求不递增版本号，也不移动已经建立的基线标签。

## 仓库范围

Git 仓库位于当前工作区根目录，覆盖：

- `work/sony-a7iv/`：适配源码、构建/分析/审计脚本、研究记录和固定版本清单。
- `outputs/sony-a7iv-qemu/`：使用文档、启动器、运行脚本、补丁、配置，以及已冻结的验证 JSON、截图和诊断证据。
- 根目录的 `VERSION`、`.gitignore`、`.gitattributes`。

未纳入 Git：固件与分区/启动镜像、编译产物、Python 缓存、临时截图、常规运行日志和本机环境文件。这些文件保留在原位置；版本管理不改变当前运行的虚拟机。已冻结并放入 `native/evidence/` 的诊断样本及日志属于验收证据，随版本提交。

因此，克隆或检出仓库仍需另行准备本机 WSL、QEMU 和固件数据，具体依赖及镜像 SHA-256 见 [项目进展报告](项目进展报告.zh-CN.md)。历史文档引用的常规运行日志和镜像可能只在当前电脑存在。

## 常用操作

在仓库根目录执行：

```sh
git status --short
git log --oneline --decorate -5
git show v0.1:VERSION
git diff v0.1
```

当前只建立本地版本控制，没有配置远程仓库或上传 GitHub。当前电脑未配置 Git 作者身份，本仓库使用本地身份 `Codex <codex@localhost>`，不修改全局 Git 配置。

基线记录的功能是原厂主界面、菜单、Fn、虚拟卡媒体数据库写入、空卡回放及实际重启；取景、对焦与照片生成尚未实现。
